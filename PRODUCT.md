# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Employees working on an existing project, their teammates, and receiving teams responsible for missing information or infrastructure requests. Hackathon judges evaluate the cross-team workflow in a short live demo.
## Product Purpose
MasterMind connects project teams to permitted knowledge and owning teams. Search existing sources first; when evidence is missing, route a question to the verified owner. Return the answer and make it reusable only after owner approval.
## Operating Context
Existing Jira projects, Confluence documentation, Microsoft Teams conversations, SharePoint policies, incoming and outgoing team inboxes. The project and its goals originate elsewhere.
## Capabilities and Constraints
Preserve working project selection, team scope, cited answers, automatic question handoff, inbox replies, approval, reuse, guided infrastructure requests with review before submission, persisted demo sessions, measured activity. No brainstorming, project planning, provisioning, fake impact metrics, real Azure or Jira integrations. Demo uses fictional records and deterministic retrieval. Azure Foundry student integration is future work.
## Brand Commitments
MasterMind. Original overlapping CPU-chip logo in Mastercard red, gold, and orange. User requests a distinctive alternative UI on a separate branch, preserving the first version. User delegates design choices and sets a 15-minute time limit.
## Evidence on Hand
Working app/page.tsx, 25 engine regression tests, tests/api.smoke.mjs, docs/DEMO.md. No testimonials or validated productivity claims.
## Product Principles
Evidence before escalation. Clear ownership. Permission-aware context. Reuse after approval. Make the next action obvious.
